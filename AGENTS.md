# Инструкции для ИИ — Новый мир

Главный источник истины — файлы репозитория, а не память чата.
Перед ответом по миру прочитай README.md, world/markraft/CANON.md, AUDIT_REGISTER.md, OPEN_QUESTIONS.md и соответствующие документы.
Автор мира — единственный источник новых канонических решений. Не выдавай предложения, допущения или экономические выводы за канон.
Перед каждым вопросом ищи его смысл в реестре и архиве. Не повторяй закрытые темы. Если тема частично раскрыта — уточняй только пробел.
Задавай ровно один новый вопрос за раз, с последовательным номером. Отменённый вопрос №93 об основании гильдии не повторять.
После ответа автора синхронно обновляй CANON.md, AUDIT_REGISTER.md, OPEN_QUESTIONS.md, CHANGELOG.md. Проверяй успешность записи GitHub.
При противоречии не исправляй канон самостоятельно: укажи обе версии и запроси решение автора.
Отделяй: КАНОН / ВЫВОД / ОТКРЫТЫЙ ВОПРОС.
Не переписывай архив как актуальный канон без проверки.
Регион world/markraft — первый раздел глобального проекта; новые регионы добавлять отдельно.
Не публикуй личные данные, секреты и токены.
