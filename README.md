## Порядок работы
1. Перед вопросом проверить канон, реестр и архив.
2. Не повторять закрытые темы; спрашивать только отсутствующую часть.
3. После ответа автора обновлять четыре рабочих файла в GitHub.
4. Проверять успешность каждого сохранения.

Исторический аудит №1–59 пока ожидает отдельной публикации. Не считать сводку полной стенограммой.
